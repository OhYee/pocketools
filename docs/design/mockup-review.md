## 验收方法与证据边界

- 使用视觉检查工具以原始分辨率逐张完整查看第二轮源图，核对页面覆盖、五态连续性、关键中文、FR-047、响应式层级和禁止项。
- 使用文件工具分别核对第二轮六张源图与六张候选的尺寸、不透明状态和 SHA-256。源图均为 `1672 × 941`；`3840 × 2160` 只是后处理规格化后的评审候选，不是模型原生 4K。
- 第二轮候选下采样后与同名源图的归一化 RMSE 为 `0.0120～0.0165`，未发现首轮文件或不同资产错配。
- `gpt-image-2` 与 `high` 仍是任务请求参数；本验收没有取得第二轮生成通道或 model metadata 的新增机器可验证证据，也没有调用图像生成。
- 图片只证明静态视觉意图。字段边界、键盘、焦点、屏幕阅读器、200% 字体、错误、离线、中断恢复、平板重排和精确动效参数仍由交互文档、tokens 与实现测试承担。
