## 否决原因

- 用户已否决旧 built-in 图片和既有“通过”“带约束通过”等复核结论；旧状态不再具有门禁效力。
- 旧稿没有覆盖更新后的 FR-047 自定义骰池字段、预设到自定义切换、完整骰池结果和四工具五态动效分镜。
- 旧稿存在生成文字不可靠、页面组合与最新范围不一致、组件细节不能精确测量等问题，无法承担开发还原基线。
- 旧稿生成方式、输出规格和质量档位不满足当前 G1 只接受执行时最新 gpt-image-2 CLI、`3840 × 2160`、`high` 的要求。
- 旧稿不能证明字体、图标、抽象牌面或其他视觉元素具备商用、再分发或公开发布许可。
